# Growth Kriya — React Redesign Phase 1

## Install in your existing `gk react` folder

Copy all starter files into `gk react` (preserve your own assets if any). In VS Code terminal:

```bash
npm install
npm run dev
```

If you already have a Vite project with existing dependencies, you can instead copy `src`, `index.html` and `vite.config.js`, then install packages as needed.

## Included
- Responsive sticky header and full Services mega dropdown (Media, Printing, Digital)
- Responsive mobile navigation
- Full bespoke landing page with Hero, About, Services, Process, Industries, Gifting, inquiry form
- Dark footer with navigation
- Tailwind v4 utility classes in JSX, shared `index.css` only; no separate page stylesheets
- AOS reveals, Lucide icons, React Router
- Placeholder routes for future pages (not completed service pages)

## Important before publishing
- Wordmark in header/footer is a **temporary text-based treatment**, not the client's verified original logo. Replace with client logo asset when supplied.
- Landing images are remote Unsplash placeholders, not Growth Kriya-owned brand assets. Replace with licensed/client-approved artwork.
- Form currently opens the visitor's email client with a drafted enquiry. **No submissions are stored or delivered automatically.** Configure a PHP endpoint/API and client-confirmed recipient before launch.
- Final company phone, address, social handles and real portfolio assets not verified; intentionally omitted.
- Review all copy and future detail routes with the client before publishing.
